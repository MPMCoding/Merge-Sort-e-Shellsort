Merge Sort & Shellsort

Ordenação, desempenho e memória

Daniel
Merge Sort · base teórica

Dividir para conquistar

Daniel

"O Merge Sort funciona com base no princípio de "Dividir para Conquistar". Ele divide recursivamente o vetor ao meio até que cada subvetor tenha apenas um elemento. Depois, ele combina (intercala) esses subvetores de forma ordenada utilizando um vetor auxiliar."

Fluxo do algoritmo

1. Divide

[7, 3, 5, 1] vira [7, 3] e [5, 1].

2. Resolve

As metades continuam sendo divididas até sobrar um único item.

3. Une

As partes retornam já ordenadas: [3, 7] + [1, 5] = [1, 3, 5, 7].

O preço da previsibilidade

Daniel

"Não trabalha bem em sistemas com memória muito restrita. Para juntar as duas metades de um vetor, ele precisa alocar um vetor temporário do mesmo tamanho do vetor original para organizar os dados antes de devolvê-los ao local correto."

Daniel

"Mergesort é melhor para quantidades mais massivas de dados."

Leonardo
Merge Sort · implementação em C

Código central

void mergesort(int *v, int n) { int *c = malloc(sizeof(int) * n); sort(v, c, 0, n - 1); free(c); } void sort(int *v, int *c, int i, int f) { if (i >= f) return; int m = (i + f) / 2; sort(v, c, i, m); sort(v, c, m + 1, f); if (v[m] <= v[m + 1]) return; merge(v, c, i, m, f); }

Pontos para explicar

mergesort cria o vetor auxiliar.

sort faz as divisões recursivas.

merge intercala as metades em ordem.

O teste v[m] <= v[m+1] evita processamento desnecessário.

Fonte do código: gist.github.com/olegon/mergesort.c

Shellsort · introdução

A ideia do gap

📏

Comparações distantes

Em vez de comparar só vizinhos, o Shellsort compara posições mais afastadas, o que acelera o reposicionamento de elementos muito fora do lugar.

⚙️

Gap

Gap é a distância entre os elementos comparados. Esse valor vai diminuindo até chegar em 1.

Matheus
Shellsort · sua lógica prática

Como ele age no vetor

1️⃣

Agrupa por distância

Cada passada organiza elementos separados pelo mesmo gap.

2️⃣

Antecipação

Elementos muito deslocados andam mais rápido rumo à posição correta.

3️⃣

Fechamento

Quando gap = 1, a última etapa fica mais leve porque o vetor já chega quase ordenado.

Resumo da ideia: o Shellsort faz parte do trabalho pesado antes do fim, em vez de deixar todos os deslocamentos longos para uma única passada final.

Matheus
Shellsort · análise

Vantagens e limitações

Vantagens

É in-place, então usa pouca memória extra.

Não precisa de recursão.

Pode superar o Insertion Sort em vetores pequenos ou médios.

Limitações

Não é estável.

O desempenho depende da sequência de gaps.

Com sequência simples, o pior caso pode chegar a O(n²).

Resumo

Merge Sort

  • Divide o vetor ao meio recursivamente até sobrar 1 elemento.
  • Intercala (merge) as partes em ordem usando um vetor auxiliar.
  • Complexidade sempre O(n log n), melhor e pior caso.
  • É estável: mantém a ordem relativa de valores iguais.
  • Precisa de memória auxiliar O(n) — não é ideal para memória restrita.
  • Melhor escolha para volumes de dados grandes.

Shellsort

  • Compara elementos separados por um "gap" em vez de vizinhos.
  • O gap vai diminuindo a cada passada até chegar a 1.
  • É in-place: usa pouca memória extra, não precisa de recursão.
  • Não é estável.
  • Desempenho depende da sequência de gaps escolhida.
  • Com sequência simples, o pior caso pode chegar a O(n²).
  • Bom para vetores pequenos/médios ou já quase ordenados.
